# NO AGI Free AI Catalog

Исследовательский каталог бесплатных и условно бесплатных AI-сервисов, API, агентов и программ доступа для сообщества NO AGI. Он помогает найти кандидатов и сравнить условия из исследований; наличие записи не гарантирует действующий бесплатный тариф.

## Как открыть и искать

- [Открыть Markdown-каталог](CATALOG.md) · [CSV](catalog.csv) · [Данные JSON](data/catalog.json)
- HTML-страница находится в `index.html`. После публикации через GitHub Pages её адрес можно добавить сюда; локально файл открывается в браузере без установки программ.
- Ищите по сервису, модели или описанию. Фильтры категорий, видов доступа, карты, телефона и возможностей основаны на заполненных исторических полях исследования 124; неизвестное не считается «нет». Фильтр не находит записи, для которых поле отсутствует.
- В карточке разверните «Подробнее», чтобы сравнить условия двух исходных каталогов. Несовпадение формулировок может означать разные даты, программы либо ошибку — проверяйте источники.

## Что означают статусы

**Официальный источник** означает, что конкретное указанное условие сверено с официальной страницей на дату в карточке. **Исторические данные** перенесены из исследований 17 ноября 2026 года и требуют актуализации. **Исторически завершено** означает, что исследование 124 указало завершение; текущий статус необходимо проверить. **Требует проверки** означает, что условий в импортированных карточках нет. Статусы исходных исследований сохранены отдельно и не переносятся автоматически как текущие.

Исследование было кабинетным: регистрация и API-вызовы не тестировались. Условия, цены, доступность в стране, политика данных и наборы моделей могут измениться. Сервисы могут ограничивать бесплатный доступ, требовать верификацию или платёжные данные.

## Источники и полнота

Указатель содержит 292 записи. Исторические поля перенесены из 111 подробных карточек и 119 из 124 записей дополнительного каталога; оставшиеся пять и метод сопоставления приведены в [отчёте](reports/import-124.json). Названия и разные программы не объединялись только по домену. Полный архив переписки в репозитории не публикуется. В данных сохраняются ссылки на источники и даты исходных исследований.

## Исправления и добавления

Откройте [issue](../../issues/new/choose), выберите шаблон и приложите ссылку на официальные условия, дату и конкретное изменение. Не включайте ключи, персональные данные и реферальные ссылки. Подробная инструкция для редакторов — [CONTRIBUTING.md](CONTRIBUTING.md).

## Сборка

Нужен Python 3. Выполните `python3 scripts/build.py`. Единственный редактируемый каталог — `data/catalog.json`; HTML, `CATALOG.md` и CSV генерируются из него.
