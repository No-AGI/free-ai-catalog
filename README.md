# NO AGI Free AI Catalog — черновик

Исследовательский каталог кандидатов на бесплатный или условно бесплатный доступ к AI. Все записи первоначального импорта требуют проверки: наличие записи не подтверждает бесплатный тариф или работоспособность сервиса. Условия, страны и политика данных неизвестны, пока не приведены актуальные источники.

## Просмотр и сборка

Откройте `index.html` в браузере. Исходные данные — `data/catalog.json`; HTML и `catalog.csv` генерируются из них командой `python3 scripts/build.py`. Для GitHub Pages опубликуйте корневую папку ветки после размещения репозитория. Страница работает без сервера и зависимостей.

## Обновление

Одна запись — отдельная программа или предложение. Сохраните `id`, добавьте источники каждого существенного условия и дату проверки. `null` или пустой массив означает неизвестность, а не отсутствие функции. Статусы: `needs_review`, `official`, `community`, `ended`. Не считайте ошибку доступа к сайту доказательством закрытия. Не сливайте продукты только по общему домену. Происхождение импорта указано в каждой записи; исторические наблюдения не являются текущими подтверждениями. Полный исходный архив в публичный репозиторий не включён.

Поля категорий, типа доступа, стран, карты, телефона, tools и streaming предусмотрены в данных, но в первой версии не заполнены и фильтры по ним не включены. Не отображайте их как подтверждённые до проверки. Для подтверждённого статуса сборщик требует `verified_at` и `evidence`; факт платного или бесплатного доступа необходимо проверять отдельно по официальным условиям.

## Предложить исправление

Создайте GitHub issue: название и ссылка на сервис, что изменилось, ссылка на официальные условия или документацию, дата проверки, страна и точная цитата или краткое описание. Не включайте ключи, личные данные и реферальные ссылки.

## Ограничения импорта

Импортированы 292 позиции указателя без новой проверки; названия, алиасы и ссылки перенесены как в источнике. Сопоставление объединений не пересматривалось. Некоторые позиции могут оказаться закрытыми, платными, не сервисами или повторяться. Данные из остальных разделов исходного исследования не превращены автоматически в актуальные карточки. Условия сервисов следует проверить перед публикацией рекомендаций.
